Found a broken link, typo, unclear instruction, missing file, or notebook error? Please
[open a course-material report on GitHub](https://github.com/QMCSoftware/MATH565Fall2025/issues/new?template=course-material-problem.yml).

In your report, include:

- the exact page URL or repository file path;
- a short description of what is wrong;
- what you expected instead; and
- steps to reproduce the problem, including the error message and computing environment when relevant.

Screenshots can help, but first remove names, grades, student IDs, email addresses, access tokens,
and other private information. GitHub reports are public.

For questions involving your grade, an accommodation, personal circumstances, a security concern,
or anything else that should not be public, do **not** use GitHub. Contact the instructor through
[Illinois Tech email](mailto:hickernell@illinoistech.edu) or the private course communication channel.

Before reporting a problem with a local copy of the repository, update it and its submodules if you
can. If the problem remains—or if you are unsure how to update—please report it anyway.
